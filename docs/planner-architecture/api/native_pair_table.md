# 官方机器人实体对的原生数值接口

代码基线：`NATIVE_IMPLEMENTATION_COMMIT`。实现为 `manipulation/_coal_scene_batch.cpp` 的 `NativePairTable`，由 `RobotGeometryChecker` 调用；[组件职责](../02-observation-and-collision.md)说明模型来源、规划场景和执行检查的关系。

研究对象是同一固定机器人的官方凸实体、解析盒体和圆柱。实体形状、连杆固定关系来自官方配置；当前位姿由具名关节反馈或名义关节状态、标定和 Pinocchio 正运动学确定。任务实体仍由原观测场接口计算。这里的计算结果描述所声明机器人模型的几何关系。

## 输入、所有权与调用关系

`NativePairTable(shapes, indices)` 接收 Coal 形状序列及原生字节序 `intp[P,2]` 索引数组，验证索引范围，复制有序端点索引并保存每个形状的强引用。`P` 为实体对数量，`G` 为表中形状数量。原 Python 容器后续改变不影响表的索引或形状生命周期。形状由模型保持不变，表中不保存求解器或此前数值结果。

`query(poses, projection_mask, request)` 接收原生字节序 `float64[S,G,4,4]` 位姿、`bool[S,P]` mask 和 Coal 冷距离请求。`S` 为本批状态数。矩阵表示 `T_reference_geometry`，把实体局部坐标变换到参考坐标；参考系来自基座标定。输入需为刚体变换，上层 `_prepare_query` 验证标定并由 FK 构造矩阵；原生接口读取前三行数值。数组可为带步长的切片，形状与数值类型须符合接口。

调用开始时在持有 Python GIL 的范围内复制矩阵、mask 和请求；数值循环释放 GIL，每对以独立冷 Coal 求解器计算。结果是独立拥有内存的 `float64[S,P,12]` 数组，按原状态和配对顺序写入。异常恢复 GIL，报告状态与配对索引；Python 批次入口补充该块在完整输入中的状态范围。`storage_nbytes` 返回表自身向量容量及对象占用，不重复计已有模型形状，不包含临时求解器与查询数组。

`RobotGeometryChecker.query` 使用同一表查询一个状态，关闭投影 mask，并组织完整 FK、关节限位和距离报告。`query_pair_batches` 连续准备多个状态，按配对总量分块并转为现有 JSON 证据所需的 Python 数值列表。`pair_evidence` 将原 `PairQuery` 身份、策略和来源附到数值行。`OnlinePlanningScene._robot_self_components` 消费该列表，保留未知运动处理、距离分类和穿透见证导数。机器人验证与执行前检查继续消费完整报告。

## 输出列与数值语义

| 列 | 数值与用途 |
| --- | --- |
| 0 | Coal 有符号距离，单位米；原数值分类和穿透残差使用此值 |
| 1–3 | 第一实体见证点，参考系 xyz，单位米 |
| 4–6 | 第二实体见证点，参考系 xyz，单位米 |
| 7–9 | 第一实体指向第二实体的 Coal 法向，无量纲；用于原局部导数及分离投影方向 |
| 10 | 双见证之差减去距离乘法向所得向量的欧氏范数，单位米；诊断字段 |
| 11 | 两个完整实体的非负分离距离下界，单位米；仅在对应 mask 为真时消费，关闭时为零 |

原始距离、见证及法向中的非有限值使当前原生块失败。配对策略和未知手部运动由 Python 消费者解释。投影 mask 控制下界工作，不跳过原始距离计算，也不改写未知运动分类。

## 分离下界与舍入

令参考系中的完整实体为集合 A、B，Coal 返回方向为 n。Boost.Interval 计算包含两个实体全部投影的区间 `[a₋,a₊]`、`[b₋,b₊]`。区间乘法和加法同时覆盖原形状、旋转与平移计算的舍入。以向下舍入的端点差构造

`g = max(0, lower(b₋ − a₊), lower(a₋ − b₊))`。

以向上界定的平方和与平方根得到 `N ≥ ‖n‖`；`N>0` 时返回区间商 `g/N` 的下端点。实数投影分离定理给出 `dist(A,B) ≥ g/‖n‖ ≥ g/N`，零方向的下界为零。该计算复用同一扩展中 `SpatialQuery` 的 `norm_interval`、`shape_projection` 和外向区间算法。`RoundingGuard` 只包围支持投影、范数界和区间商，退出时恢复调用者舍入环境。Coal 距离和 FK 位于该作用域之外。

下界提供分离证据；零值表达当前方向没有证明正分离。原生数值容差仍由原距离分类消费，不作为支持区间的误差界。

## 调度与资源

规划批次通常最多计算 4096 个实体对；单状态超过此数时保留一个完整状态。请求检查位于逐状态准备、块前后与逐对证据消费。取消最迟在当前原生块结束后传播。

固定表实际存储计入 `cpu_resident`；需要构造或替换的表容量计入 `cpu_pending_shared`。矩阵、原生变换、mask、输出数组、Python 数值行和一个冷求解器计入 `cpu_live`，该临时项在表已存在时继续保留。若每状态配对数为 P 且引用 G 个实体，G≤2P，因此普通分块满足 SG≤8192；单状态大表按完整模型容量计数。状态准备的完整 FK 临时字典也计入模型容量，形状本身由固定模型持有。
