一、结论和责任

用户报告的退化属实。四份附件在同一参考、同一物理时间上独立复算后，当前位置 RMS 为 288.8279 mm，路径长 5.8212 m，最大偏离 589.1664 mm。R9 对应为 80.2995 mm、1.5793 m。这不能归结为网页投影、不同参考或者不同时间参数造成的统计错觉。

此前建议的组合没有得到充分的端到端验证：把最终资格排序用于数值暖启动，删除失败关节观测后依赖后续优化补齐，以及对整条优化方向统一限步，这几项共同形成了明显副作用。对于这些建议的适用条件与组合风险，先前说明不足。此次不再把单个局部测试通过、恢复器能够触发、迭代次数增加或一个误差指标下降称为系统改善。

本轮唯一主建议是：把参考初始化收敛为一个在现有曲线控制量上的受约束工具空间拟合，用完整迁移参考直接构造连续关节曲线，并沿用原功能事件允许集合。它替换现有的稀疏关节粗拟合及效果不足的细化，不在其后再串联一个补救阶段。reference IK 只负责连续的数值起点；主优化和最终资格继续负责原任务与场景要求。初始化与主优化若共用方向机制，也必须共同解决当前标量限步对前段的冻结。

这个方向已有真实参考上的运动学可行性证据；完整任务可行性和低频实时性尚未得到证明。本文明确给出实验范围、负面结果和实现热点。生产源码未修改，没有执行机器人、提交 commit 或 push。

四、代码中的确定问题

4.1 最终资格前缀被误用于 reference 数值延续

planning_ik.py:78 的 _qualification_prefix 按字典序比较：已知 task 失败、已知 model 失败、reference pose 失败、task 未建立、model 未建立。

planning.py:4851 在 reference IK 位姿失败时跳过静态模型查询。这样两个候选可能得到：
位姿成功、已测自碰撞：(False, True, False, False, False)
位姿失败、模型未检查：(False, False, True, True, True)

后者在第二个元素已取得优先级。它不因为已经测得碰撞而受罚，但也没有提供成功参考位姿。这个前缀同时被局部 rank、tracking 暖启动和整链 DP 使用；planning.py:4062 又把 tracking 结果赋给下一次 IK 的 seed。

DP 选择该状态后，planning_ik.py:275 将其 observation_mask 置 False；planning.py:4193 随后从 q 拟合目标移除该状态。数值候选仍传向下一查询，但参考信息已经丢失。tests/test_planning_ik.py:286 还明确断言这种排序，所以测试全绿不能否认这次策略错误。

生产函数反事实：同样 18 个候选池，每池都有已构造的连续成功 q；前 5 个报告模型通过，后 13 个报告自碰撞，并提供 failed+unchecked 备选。报告中的碰撞是测试输入，不是原机器人 Coal 计算。所有政策均进入当前同一个 QP：
前次政策18516db：成功观测18、秩18、q RMS 3.35e-14 rad、终点0.4 rad。
当前政策622065a：成功观测5、秩5、q RMS 0.2523055 rad、终点0 rad。
reference-native-first反事实：恢复18个观测和原曲线。
三者最终 q/v/a/jerk 连续边界都通过。

此实验隔离了排序→丢观测→粗拟合退化机制，不证明原 CUDA IK 的 14→7→5 计数变化全部由它造成。那些计数仍来自用户记录。

修改职责：reference continuation 应保留已收敛且连续的位姿数值解；已知碰撞报告继续交给实际碰撞优化与最终资格，不把候选当成可执行轨迹。成功集合中仍须避免远构型无条件压过连续近邻。functional IK 应继续使用原允许集合，不能套用“必须到达名义六维中心”的 reference 判据。

4.2 五个关节观测没有定义整段工具路径

physical_joint_qp.py:308 的 fit_cubic_reference 实际优化：
  min_C 1/2 ||B_obs C + b_obs - Q_obs||² + λ/2 ||C-C_entry||²
并约束连续 q/v/a/jerk。

其 Hessian 是 B_obsᵀB_obs + λI，λ 约为 64 eps64 max(1,trace(B_obsᵀB_obs))。在实际18控制量基函数和时钟上构造的示例五点布局中，λ≈3.4e-14、H条件数约2e13；这些并非原始五个成功点的索引，原始索引日志不在附件中。

五个观测对应 5×18 矩阵，秩至多5。每关节至少13个方向没有观测信息，七关节至少91个方向。微小正则项在这些方向上仍然主导解；入口 prior 没有携带迁移参考，物理边界也不包含工具目标。因此它能得到“关节四阶边界合格、TCP却返回入口并绕行”的曲线。

不能把此事修成新的 rank 阈值或增加一个拒绝器。应改变实际拟合目标，让整段工具参考从曲线第一次构造时就提供信息。失败 IK 的数值结果可以提供起点，但不能作为真实参考观测。仅丢弃这些观测、把修正寄托于之后的主优化，是不完整的工程改动。

4.3 参考梯度存在，统一标量限步却可把整条方向压到零

reference_tracking.py:224 对全 ordinary horizon 计算工具参考代价。真实当前曲线上的前16组控制量各自最大梯度约3381–16655，不是零。

用独立解析 FK/Jacobian 校验原生 NativeReferenceCost，位置项和旋转项梯度的相对 L2 误差分别4.24e-8、8.04e-8。另一 agent 读取官方 quaternion VJP 协议并做 rotation-only 有限差分，也通过。因此不要再次修改已正确的 native 四元数梯度适配符号。

physical_joint_domain.py:101 将所有控制量沿同一个方向统一乘 α。实际当前曲线第一关节在7.693678550 s的速度只比实验下界高3.50271e-9 rad/s，归一化参考负梯度使该速度沿单位 α 再降低2.2583721 rad/s，故：
  α ≤ 3.50271e-9 / 2.2583721 = 1.55099e-9。
原限步输出为零。这个上界说明调高二分精度没有解决方向不合适的问题。

现有恢复 QP 能找到合法下降方向，走0.1倍就使原生参考代价从190555.25降至157738.45。“这条方向不能走”与“没有可行下降方向”不同。

这组实验使用 XML 关节位置界，速度前四±2.175、后三±2.61 rad/s，加速度±15 rad/s²，jerk±500 rad/s³。后两者及速度取本地官方 Franka 配置；solver实验以float32端点绑定，root原型以float64声明绑定，不能把两种细微不同的端点混用。不是原缺失robot.json的完整重放。

4.4 尾部大梯度和全 seed 停滞判断形成选择性冻结

planning_problem.py:1561 对位置事件使用(error-tolerance)/tolerance；以2 mm、AL初始ρ=2、constraint_weight=1e5计算，违规位置项二次系数为2.5e10 m⁻²。全程参考位置项系数是0.5×1e6 m⁻²且按物理时间平均。任务零集没变，但数值条件差很多。

在真实当前曲线上加入两个隔离用TCP位置事件后，末组梯度约3.32e9。原生共享归一化因子585300使前16组方向降到2.85e-5 rad，再经标量物理限步仅约8.94e-9 rad，尾部仍能动约1.78e-3 rad。

同一native CPU生命周期50次迭代：
完整参考单项：2次有效更新/2次恢复，位置RMS207.98mm。
完整参考+两个TCP位置事件：49次有效更新/0次恢复，前16组最大变化1.62e-6rad，位置RMS287.79mm。

这些位置事件来自同刻参考TCP，特意用于数值隔离，不是完整原始材料/支撑/朝向事件。也不是原粗曲线50次迭代日志的重放。

curobo_solver_components.py:437 用整条seed最大变化和总目标下降清零stall；尾部持续进步掩盖前段冻结。新版已把block末recovery触发修为stall>0，不能再把旧触发门槛当本次唯一原因。增设逐关节stall阈值只会继续堆补丁。只把事件归一化尺度改为0.1m、保持2mm允许集合不变的反事实也未解除前段冻结。

4.5 主优化之前，对已经明确失败的初值重复做完整资格流程

planning.py:6039-6057 的顺序是 evaluate_reference → select_candidate → main optimize。
前者经 _observed_native_result 查询 ordinary/interpolated full-scope metrics；后者再计算 fixed objective、saved-curve metrics。初始化snapshot有时已经明确给出同一曲线的正功能违约，仍消费这轮完整场景扫描。

当前代码只有在离散指标accepted后才做 interval_geometry（planning.py:5329）。本文不声称所有失败初值都运行连续几何证明。

最小调度修复：当 joint_reference=None 且所有同曲线初值都有明确、有限、正的功能违约时，直接送入原主优化。最终候选仍走原完整资格。只由unknown coverage造成的不合格、可能合格的其他seed、用户提供完整joint_reference的快速交付路径均保留。

实际plan_trajectory调用顺序反事实已覆盖五种分支：全候选已知任务失败、主优化后仅unknown、混合候选、初值仅unknown、完整joint_reference incumbent。当前序列可在scan耗尽预算而main=0；修改后可main=1并保留原最终unknown策略。实验用现有CPU编排fixture和显式预算异常模拟，只证明调度，不是原场景加速倍数。

五、已经排除和仍然未知的解释

1. 在当前生产树的定向检索中没有发现TCP几何曲率κ或挠率τ限制。curobo_solver_components.py:380附近的curvature是L-BFGS的sᵀy数值曲率，不是路径几何限制。本任务无需新增κ/τ门槛；保留正常q/v/a/jerk物理要求即可。没有根据少数版本数据宣称严格数学意义的指数增长。
2. 整段reference梯度和native quaternion VJP经独立校验正确。
3. current_state=self.start不是本轮已证实的错误。所查官方IK配置optimization_dt=None、cspace目标权重0、位置形式的速度/加速度正则未启用、use_lm_seed=False，且显式seed_config=previous。current_state主要影响返回排序中的start distance；不能保证改成previous就恢复IK收敛率。
4. 相同进度映射及相同冻结参考已验证，不能把这次退化转嫁给参考版本不同。
5. 全程参考是否完全可达、原始完整功能允许集合是否自洽、真实模型/场景能否无碰撞完成仍未由本轮输入确定。先前尾部多次IK停滞不是全局无解证明。

六、真正测试过的更小修法与替换原型

6.1 只撤掉标量限步，不够

按实例去掉limiter/recovery，保留原native L-BFGS、原生ordinary cspace成本、原生q/v/a/jerk罚项及AL生命周期，最终仍用连续物理域检查。匹配对照同为当前曲线、完整参考、两个隔离TCP位置事件和50次迭代。

保留limiter：位置RMS287.79mm，前16组最大变化1.587e-6rad，最终q/v通过。
去掉limiter：位置RMS233.54mm，前16组最大变化0.16193rad，但q越界0.02427rad、v越界0.19217rad/s，一个位置事件失败。
较好reference-lift初值去limiter：位置RMS25.15mm、姿态RMS0.05248rad、路径0.86471m，两个隔离TCP位置事件通过，但q越界0.05377rad。

结论：每个数值迭代都物理合格不是用户对最终轨迹的必然要求；自制标量限制确实有副作用。但有限原生罚项在50步内未保证最终边界，直接删除不能作为完整修复。这不意味着GN/SQP是唯一算法，只说明该更小修改没有完成本例的子问题。

6.2 真实参考上的联合工具空间拟合

原型保持同一入口、同一物理时钟、同一18×7自由控制量。81个等时采样点提供位置和SO(3)log误差，物理时间积分权重一致。目标为：
  1/2 Σ w_i (||Δp_i||² + 0.2||Log(R_ref_iᵀ R_i)||²)。
这是原位置/旋转尺度的运动学表达，不是直接调用原native ToolPoseCost；也没有完整ordinary成本、原功能允许集合或碰撞。因此它是替换方向的可行性实验，不是“原完整优化器只改一个方向”的纯单变量对照。

一步联合QP的模型：
  min_δ 1/2 ||W^(1/2)(r+Jδ)||² + μ/2 ||δ||²
  约束原连续q/v/a/jerk界及事件的当前线性化。
J包含机器人Jacobian和样条basis，七关节互相耦合，不能用七个独立18维QP冒充126维联合问题。

先做连续局部有界IK得到数值起点，使用80次CPU查询。该过程没有宣称所有查询成功；最大相邻q步长仍约2.923rad，尾部部分查询达到迭代上限。它仅用于起点，原型最终目标不会把这些近似q当成精确工具参考。

事件坐标在独立评审后修正：若A=T_carrier,eef，则
  T_world,carrier = T_world,tool A^(-1)
  p_carrier = p_tool + R_tool t,
  J_carrier = J_p - [R_tool t]_× J_ω，t=translation(A^(-1))。
只固定TCP原点会因姿态与固定偏置带来约11.38mm材料原点误差。v2改为两个由同刻参考导出的材料原点位置中心；原型仍未覆盖全部原始功能事件。

初版v1曾有约1e-8量级中间物理超界，并只锁TCP位置。独立评审发现后，v2复用既有物理域检查实际trial，改用声明材料原点映射，保留v1记录以供审计。未通过放宽物理边界修正。非线性事件仅逐次线性化，因此不声称中间每步满足最终事件；入口起点最终仍有1.73mm残差。

6.3 性能证据及原型限制

连续IK准备4.547s、q拟合0.158s、v2 GN50步13.394s，合计约18.10s。入口常值起点GN15.253s。均为CPU隔离实验，未计完整场景，不能声称低频实时后端已达标。

独立短profile（10步、与既有run前10步cost完全一致）：总循环2.217s，QP kernel0.821s，连续极值0.729s，约束组装0.295s；reference残差/Jacobian仅0.015s，JᵀJ仅0.0038s。每步打满12轮exchange，共120次QP，每次约1342–1484条约束；50步就是600次QP。

因此不能原样移植原型的严格零超界exchange循环，也不能把主要性能工作投向本例耗时很小的FK残差。应统一现有连续域及目标dtype数值处理，复用固定basis/约束结构、复用QP工作区并消除重复方向构造。真正完整时延仍需要原后端实测。向内扩大构造裕度会缩小内部可行域，边界事件可能因而被排除；不把这种margin当作无条件、无影响的性能修复，不新加物理拒绝阈值。

七、唯一主建议的工程落点

7.1 初始化接口的职责

输入继续使用：迁移参考T_ref(t)、已有入口q0/dq0、已编译功能事件允许集合、已有机器人/场景模型、现有预算与物理时钟。
输出是同一原生曲线表示的数值初值C，以及原有诊断信息。是否可执行由原完整候选资格判定。

数学目标：
  q(t;C)=B(t)C+b(t)
  min_C Σ_i (Δt_i/T) Φ(FK(q(t_i;C)),T_ref(t_i)) + 原有关节平滑项
  s.t. 已有连续q/v/a/jerk边界；T_material(t_e;C)∈原功能允许集合F_e。
完整主优化继续包含模型自碰撞、场景实体碰撞、接触与覆盖等原始要求。参考全程为软目标，必要绕障和不可达参考允许有跟踪误差；实际交互允许集合保持任务定义。

7.2 具体代码修改

A. planning_ik.py / planning.py:_reference_ik_query
修reference暖启动和chain的信息保留语义，成功位姿与连续性参与数值选择；保留原失败报告。functional允许集合的处理不改成reference名义位姿收敛判据。修正目前把错误排序锁进测试的断言。

B. planning.py:_fit_reference_chains、_refine_reference_seeds；physical_joint_qp.py
把工具空间受约束拟合作为一次连续求解，替换稀疏q粗拟合和无效细化。复用已有basis、时间网格、物理约束行、FK/Jacobian及参考权重；联合构造跨关节方向。以现有数量的控制量实现通用库，不写死18×7或mug。IK和补充查询只提供数值起点，不再另建一条会返回入口的粗拟合职责。已有合法完整joint_reference的资格快速路径保留。

C. curobo_solver_components.py / physical_joint_domain.py
把物理约束参与方向构造作为主机制，初始化和主求解共享对应能力。实际非线性任务与碰撞值决定步接受；最终保持原连续域与完整资格。仅在LBFGS方向后统一缩α不足以承担该职责。既有QP恢复、stall识别、独立细化若被新内核取代应删除重复职责，不继续叠加恢复器。若本轮只落地初始化，应明确主后端的同类冻结尚未解决，不能宣布系统修复。

D. planning.py:6039附近
复用同曲线已有正功能违约，跳过不可能交付的初始化全扫描，让预算进入主优化。保留unknown-only策略、可能合格的seed、完整joint_reference incumbent和最终完整验收。这个调度修改可以独立先落地，已有实际编排反事实支持。

7.3 保持物理与任务语义

最终放置要求用原材料坐标/支撑允许集合，不能恢复event IK的任意q等式；不能把自由yaw锁成完整名义姿态；不能用仅TCP原点约束替代材料点。约束尺度应服务数值条件，允许集合的2mm等任务定义不变。

低频实时的第一目标是让一次预算内的真正求解发生，并让一次更新改善完整参考。固定时钟、基函数和已有机器人模型可以复用；本轮没有证据支持更换Coal/OMPL/Pinocchio/curobo、增加新地图、引入一套新验证框架或增加曲率/挠率阈值。

本轮建议的验证使用现有测试入口及这四份固定数据：候选语义回归、连续工具参考与末端事件的同一次回归、初值/主优化/最终资格的完整一次调用。现有最终资格负责交付，不把RMS、路径长度或rank另加成生产拒绝器。这些指标用于对照修改收益与副作用。
